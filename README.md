## Удаленное шифрованное кодирование (--security)

Кодирует видео на чужой машине так, что открытый контент существует
только в RAM удаленного ffmpeg. На диске воркера — всегда шифротекст.

Профиль воркера (`~/.config/quickffmpeg/workers.json` или
`~/Library/Application Support/quickffmpeg/workers.json` на macOS):

```json
{"server1": {"host": "192.168.3.30", "port": 2222, "user": "pc", "dir": "~/qff"}}
```

Запуск:

```bash
make build-worker
quickffmpeg --crf 40 --security server1 --path ./videos
```

Как это работает: на каждый файл генерируются свои ключи AES-128,
файл шифруется, заливается по scp, кодируется удаленным бинарником
(заливается сам при первом запуске), результат забирается и
расшифровывается локально, следы на воркере зачищаются. Ключи живут
только в env удаленного процесса, в settings.txt не пишутся.

Честная граница: защищает от перехвата, копий на диске и любопытства.
От владельца машины с root и дампом памяти — нет.

## Рекурсивное сжатие (-r)

С флагом `-r` программа обходит все вложенные папки и в каждой папке
с видео создаёт свою папку `compressed`:

```bash
quickffmpeg -r --path '/Volumes/ssd m2/Видео и фото/2025/Бекап Лады/Бекап с самсунга/Samsung'
```

Папки `compressed` при обходе пропускаются, поэтому их содержимое
не попадает в повторную обработку. Без `-r` поведение прежнее:
обрабатывается только корневая папка.

## Настройка шума
- grain=0 (Выключено): Используйте только для записи экрана ПК (скринкастов), где картинка изначально идеально чистая и цифровая.

- grain=4 или grain=6: Идеально для современных цифровых видео, роликов с YouTube, геймплея и аниме/мультиков. Шум почти незаметен, но его хватает, чтобы предотвратить появление полос на градиентах (в небе или тенях).

- grain=8 или grain=10: Золотая середина для большинства фильмов и сериалов, а также видео с телефона. Сохраняет естественную текстуру кожи и одежды.

- grain=15 до grain=20: Для видео, снятых при плохом освещении (где изначально много «снега»), или для старых фильмов, снятых на настоящую пленку (например, «Матрица» или «Спасти рядового Райана»).

- grain=30+: Экстремальные значения. Применяются редко, в основном для очень специфичного стилизованного контента.
